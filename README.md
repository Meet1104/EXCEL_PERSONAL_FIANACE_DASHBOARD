# 💰 Personal Finance Dashboard – Microsoft Excel

An interactive **Personal Finance Dashboard** built in Microsoft Excel to organize financial transactions and monitor income, expenses, savings, investments, net worth, and financial goals.

The project transforms transaction-level data into an easy-to-understand dashboard with KPI cards, monthly analysis, category breakdowns, investment allocation, and financial goal progress.

## 🎯 Project Objectives

- Track total income, expenses, savings, investments, and net worth.
- Compare income and expenses across months.
- Understand spending patterns by category.
- Review how investments are allocated.
- Monitor the savings rate against a target.
- Track progress toward individual financial goals.

## ✨ Dashboard Features

### 1. Financial Overview
- Total Income
- Total Expenses
- Total Savings
- Investments
- Net Worth

### 2. Income vs. Expenses
- Monthly comparison of income and expenses.
- Helps identify changes in cash flow over time.

### 3. Expense Analysis
- Category-wise expense breakdown.
- Top expense categories.
- Percentage share of each expense category.

### 4. Savings Analysis
- Savings amount and savings rate.
- Savings-rate target indicator.

### 5. Investment Allocation
- Investment distribution across:
  - Mutual Fund
  - Index Fund
  - PPF
  - Gold
  - Others

### 6. Financial Goals Tracker
Tracks the goal amount, actual amount saved, completion percentage, and contribution for goals such as:
- Emergency Fund
- Vacation Trip
- New Car
- Retirement Fund

### 7. Interactive Filters
- Year slicer
- Month slicer

## 🗂️ Workbook Structure

The Excel workbook contains the following worksheets:

| Worksheet | Purpose |
|---|---|

| `Data` | Transaction-level financial data |
| `Summary_Table` | Supporting summary tables and analysis |
| `Financial_Goals` | Financial goals and progress tracking |

## 🚀 How to Use

1. Clone or download this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Go to the `Dashboard` worksheet.
4. Use the Year and Month slicers to filter the dashboard.
5. Review the KPI cards, charts, expense breakdown, investment allocation, and financial goals.
6. Explore the `Data` and summary worksheets for supporting information.
